NOVARA STORE - ONLINE-READY STARTER
===================================
Included storefront pages: Home, Collections, Product Details, Wishlist, Cart, Checkout, Confirmation, About, Contact, Size Guide, Shipping & Returns.

Added in this version:
- Responsive storefront for mobile and desktop
- Supabase configuration scaffold
- Supabase SQL schema with Row Level Security
- Admin login/dashboard (admin.html)
- Product add/edit/delete and stock fields
- Customer order listing and order status updates
- COD checkout submits orders to Supabase once configured
- Store categories restricted to T-Shirts and Pants

IMPORTANT: This is not live until you complete SETUP-SUPABASE.txt, configure your Supabase project, create an authorized admin user, test an order, and publish the folder over HTTPS. Do not collect real customer data until setup and testing are complete.
